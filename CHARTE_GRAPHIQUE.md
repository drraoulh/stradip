# Charte graphique — BRENTEX SARL

Trois propositions de palettes cohérentes avec l'univers maritime, BTP et énergie.
La **Proposition 1 (Maritime Classic)** est implémentée par défaut.

---

## Proposition 1 — Maritime Classic (active)

| Rôle | Couleur | Code |
|------|---------|------|
| Primaire | Bleu marine | `#0A2540` |
| Primaire clair | Bleu port | `#1A3A5C` |
| Accent | Or | `#C9A227` |
| Fond | Crème | `#F8FAFC` |
| Secondaire | Bleu ciel | `#E8F4FC` |
| Texte | Ardoise foncée | `#0F172A` |

**Typographies** : DM Serif Display (titres) + Inter (corps)

**Ambiance** : Élégance maritime, confiance, premium. Alignée avec le logo bleu/blanc existant.

---

## Changer de palette

Modifier les variables CSS dans `src/app/globals.css` (section `:root`).

Pour changer les polices, éditer `src/app/layout.tsx` (imports Google Fonts).
